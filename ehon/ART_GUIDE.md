# 作画ガイド（とびだす昔話）

このサイトの絵を描いてもらうときの仕様です。絵は「切り絵の飛び出す絵本」のように、**パーツごとに別の画像**として舞台に並べ、ページをめくるとパーツが下の辺を折り目にして起きあがります。

- 現在の絵（手描き SVG の仮素材）：`ehon/assets/art/`
- 絵の配置データ：`ehon/stories/momotaro/story.json`
- 見た目の基準：`ehon/assets/css/ehon.css`

## 見た目の方向

- **切り絵・色紙風。** 平らな塗り、影やグラデーションは控えめ。紙を切り抜いたような、はっきりした輪郭
- キャラクターには細めの焦げ茶の輪郭線（目安 `#4a3a30`）。背景（山・丘・海）は輪郭線なし
- 頭が大きめの、やさしい子ども向けの絵柄。こわすぎない鬼
- 影はサイト側で付けます（紙が少し浮いたような影）。**絵の中に地面の影を描かない**
- 既存の絵本や作家の画風をまねない

## 画像の形式

- **PNG（背景透過）** または **SVG**。WebP（透過）も可
- 1枚につきパーツ1つ。**背景を塗りつぶさない**
- **下の余白をゼロにする。** キャラクターは足（または底）が画像の下端にぴったり接するように切り抜く。サイトは画像の下端を「地面」として配置します
- 左右の余白も最小限に（トリミング済みで）
- **文字を描き込まない**（旗の「日本一」なども文字なし。多言語対応のため）
- 大きさの目安（PNG の場合、横幅）：
  - 背景の帯（山・丘・川・海・草）：3200px（横長。左右は画面の外まで続く想定）
  - 家・島・門などの大物：1200px
  - キャラクター：600〜800px
  - 小物（だんご・たらいなど）：300px

## 向きのルール

- 物語は **右へ進みます**。旅をする桃太郎は **右向き** に描く
- 犬・猿・キジ・鬼は **左向き** に描く（桃太郎と向かい合う）。仲間として右へ進む場面では、サイト側で左右反転します（`"flip": true`）

## サイトへの組み込み方

1. 画像を `ehon/assets/art/` に置く（このお話専用の絵なら `ehon/stories/momotaro/img/`）
2. `ehon/stories/momotaro/story.json` の該当レイヤーの `src` を書きかえる

```json
{ "src": "momotaro.png", "x": 49, "y": 5, "w": 16, "depth": 0.75, "anim": "bob", "tap": "momotaro" }
```

- `x`：中心の位置、`y`：下端の位置、`w`：幅（すべて舞台に対する %）。高さは画像の縦横比から自動で決まる
- お話専用フォルダの絵は `"src": "./img/momotaro.png"` のように `./` で始める
- 縦横比が変わった場合は `w` と `y` を調整する

詳しいキーの一覧は `ehon/README.md` を参照してください。

## 出典の書き方

AI で作った絵を使う場合も、最後のページの「素材・出典」に書いておくと安心です。`story.json` の `credits` の「絵」の項目を、たとえば次のように書きかえます。

```json
{
  "id": "art",
  "kind": "note",
  "label": { "ja": "絵", "en": "Illustrations" },
  "body": {
    "ja": "このサイトの依頼で、画像生成AIを使って制作しました。",
    "en": "Created for this site with an AI image generator."
  }
}
```

国立国会図書館の画像を組み合わせる場合は、`README.md` の「素材・出典の方針」に従ってください。
